# Mujer Bonita image assets

Original image files collected from https://www.mujerbonita.pe/index and image references in its linked stylesheets and scripts. Original filenames and directory structure are preserved. No images have been edited or integrated into an application.

See `manifest.json` for source URLs, local paths, file sizes, SHA-256 hashes, and any failed downloads. The collection includes hidden carousel slides, the promotional popup, and image references in commented HTML. CSS image references may include assets for other components supplied by the homepage's shared stylesheets.
